# Compatibility

| Component | Supported |
|-----------|-----------|
| BlueMap | 5.3 or newer |
| Java | 21 or newer |
| Build toolchain | Java 21 (Gradle toolchain) |
| S3 client library | `aws-java-nio-spi-for-s3` 2.5.0 |
| BlueMap platforms | Spigot/Paper, Sponge, Forge, Fabric, CLI |
| Storage services | Amazon S3, Cloudflare R2, MinIO, DigitalOcean Spaces, Backblaze B2, Ceph, and other services that implement the S3 API |
| License | GNU Affero General Public License v3.0 |

The addon needs an S3-compatible service the server can reach over the network.
